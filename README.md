A state-of-the-art, automated web application and management system built for **Auto Doc - Yomal Car Audio** (Kurunegala / Colombo, Sri Lanka).

---

## 🌟 Key Features

1. **🏠 Public Customer Showcase & Direct Booking**:
   - Modern luxury dark automotive theme with gold and neon accents.
   - Comprehensive services catalog (Android TV Displays, Subwoofers & Sound systems, 360°/Reverse Cameras, Nano Ceramic Tinting, Rat Guard Engine Protection, Seat Covers, 3M Coil Carpets, Dashcams, Security Systems).
   - Product catalog with live search and category filters.
   - Interactive Upgrade & Cost Calculator with 1-click WhatsApp quote generator.
   - Public online invoice verification tool.

2. **🔒 Role-Based Access & Security**:
   - Public landing page accessible to all visitors.
   - Internal business tools (POS Billing, Invoices, Inventory, Approvals Hub, Dashboard, User Management) protected behind Staff Authentication.
   - Roles:
     - 👑 **Master Admin (`admin` / `1234`)**: Full control, all approvals, user creation, financial reporting.
     - 💳 **Billing Cashier (`cashier` / `1234`)**: POS billing, discount approval requests, stock requests.
     - 🔧 **Lead Technician (`tech` / `1234`)**: Service jobs, inventory requests.

3. **💳 POS Billing with Discount Approval Workflow**:
   - Multi-tier pricing (Standard Sale Price, Discount Tier, Special Tier).
   - Workshop labor & custom service charge support.
   - **Discount Approval Rule**: Additional invoice discounts automatically trigger a **Pending Admin Approval** state before finalization.
   - Luxury printable invoice with QR code and instant WhatsApp share link.

4. **📦 Smart Inventory & Stock Control**:
   - Real-time stock counts with low-stock warnings.
   - Staff inventory addition requests sent to Admin approval queue.
   - Staff price change requests with Old vs Proposed New price comparison.

5. **🛡️ Admin Approvals Center**:
   - Centralized real-time hub for approving/rejecting discounts, new inventory items, and price modifications.

6. **📊 Executive Dashboard & EOD Sales**:
   - Real-time KPIs (Daily Gross Sales, Net Revenue, Discounts, Invoices count).
   - End-of-Day (EOD) Register Settlement breakdown (Cash, Card, Bank Transfer).
   - Interactive 7-day revenue trend and category share charts (Chart.js).
   - Top-selling equipment and services ranking.

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser. No server setup or external dependencies required.
